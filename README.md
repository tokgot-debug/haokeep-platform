# Vanbransa CleanPulse — Operations Monorepo

Autonomous Housekeeping & Turnover Operations Platform for Short-Let Hosts & Cleaning Agencies.

## Workspace Structure
- `frontend/` — Next.js TypeScript Web & Mobile App (App Router, Tailwind/CSS modules)
- `backend/functions/` — Firebase Cloud Functions TypeScript Backend Services & M-Pesa / eTIMS Webhooks
- `scripts/` — Provisioning, seeding & deployment helper scripts
- `docs/` — System architecture and developer workflows

## Quick Start
```bash
npm run dev      # Start frontend dev server
npm run build    # Build frontend & backend
npm run emulators # Start Firebase Emulators
```
